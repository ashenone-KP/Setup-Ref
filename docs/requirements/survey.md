# Online survey — finding a project supervisor (Google Form spec)

Build this as a Google Form (anonymous). It complements the interviews with wider,
quantifiable data. Question types are noted in **[brackets]**. Aim for 15+ responses.

## Intro (form description)
> This short (~3 min) anonymous survey is for a university project about an app that
> helps students find a final-year project supervisor. There are no right or wrong
> answers. By submitting you consent to your anonymous answers being used in the report.

## Section A — Background
1. What year are you in? **[Multiple choice: 1st / 2nd / Final / Postgraduate]**
2. Have you already looked for a final-year project supervisor?
   **[Multiple choice: Yes / Not yet / In progress]**

## Section B — Current process
3. How do you currently find which staff supervise which topics?
   **[Checkboxes: Ask staff directly / Department web pages / Word of mouth /
   A provided list or document / I don't know how / Other]**
4. How easy is the current process of finding a supervisor?
   **[Linear scale 1–5: Very hard → Very easy]**
5. What is most frustrating about finding a supervisor right now? **[Long answer]**

## Section C — What matters when choosing
6. How important is each factor when choosing a supervisor? **[Grid, rows below,
   columns = Not / Somewhat / Very important]**
   - Their research/teaching areas
   - Their specific proposed project ideas
   - How many students they can still take (availability)
   - Approachability / responsiveness
   - Past projects they've supervised
7. Do you care more about a supervisor's broad areas or their specific project ideas?
   **[Multiple choice: Areas / Project ideas / Both equally]**

## Section D — Desired features
8. Which features would be most useful? **[Checkboxes: Search staff by topic /
   Filter by area of interest / See each supervisor's project ideas /
   See supervisor availability / Bookmark/shortlist supervisors /
   Recommended supervisors based on my interests / Send a supervision request in-app /
   Track the status of my request / Other]**
9. How useful would **recommended supervisors based on your interests** be?
   **[Linear scale 1–5: Not useful → Very useful]**
10. What would you want to see first when opening the app? **[Long answer]**
11. Anything else you'd want from a supervisor-finding app? **[Long answer]**
