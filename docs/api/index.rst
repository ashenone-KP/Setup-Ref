SupervisorMatch — API documentation
====================================

SupervisorMatch is a Flask web application that helps final-year students find a
project supervisor: staff publish their areas of interest and project ideas, and
students browse, search, shortlist, receive recommendations, and request supervision.

This site documents the application's Python modules, generated automatically from
the source code's docstrings. It complements the in-code comments and the report.
